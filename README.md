# 淘宝选品与竞品情报操作台

一个**跑在你自己电脑上**的淘宝/天猫选品与竞品情报工具。输入关键词批量采集市场结果，或者粘一个竞品链接把整份资料（主图、SKU 图、详情图、评价、问大家）打包带走，全部数据只存在本地，不上传任何服务器。

> 面向淘宝/天猫运营的本地桌面工具。不做铺货、不刷单、不跨平台、不替代生意参谋——**数据来源是搜索结果页，不是后台成交数据**。

---

## 它解决什么问题

1. **选品没有可对比的市场快照**：手动翻搜索页、截图、抄标题价格销量、拼 Excel，一次两小时。现在输入关键词，商品逐条落库，一键导出带主图的 XLSX。
2. **竞品资料收集是脏活**：散落在截图、收藏夹和聊天记录里，下次要用找不到。现在粘一个链接（支持长链接、分享短链、带文案的整段分享内容），生成一份可复用的竞品档案。
3. **变化看不见**：竞品降价、上新、排名变动没人天天盯。现在可以给关键词、单品、店铺加每日监控，只看值得关注的变动。

## 核心功能

| 模块 | 能力 |
|---|---|
| 市场搜索 | 关键词批量采集、结果内搜索与价格区间筛选、价格分布分析、多快照对比、导出 XLSX（含图片） |
| 竞品采集 | 粘链接或整段分享文案自动解析；采集标题、价格、SKU、主图、详情图、评价、问大家；同一商品重复采集更新原记录，不产生重复项 |
| 竞品资料库 | 列表查看、重新采集、导出 ZIP 资料包、删除；一个商品一条记录 |
| 监控中心 | 关键词 / 单品 / 店铺三类每日监控，变化雷达自动过滤小幅波动，支持手动立即执行 |
| 本地导出 | XLSX、ZIP 资料包、HTML 分析报告，导出后可一键打开所在文件夹 |
| 可选 AI 分析 | 接入你自己的模型服务（如火山方舟），生成市场与竞品分析报告；不接入也不影响采集和导出 |

## 快速开始（Windows）

```bash
# 1. 建议 Python 3.11 及以上
python -m pip install -r requirements.txt

# 2. 启动（会自动打开浏览器）
python launch_latest.py
```

也可以直接：

```bash
python app.py --open-browser
```

启动后访问 `http://127.0.0.1:8765`。端口被占用时会自动顺延到 18765/28765 等。

### 数据存在哪里

- 默认：`%LOCALAPPDATA%\LaobingMarketIntelligence\data`
- 自定义：设置环境变量 `TAOBAO_MARKET_DATA_DIRECTORY`

内含水印数据库、导出文件（`exports\`）和图片缓存。删掉这个目录等于清空全部本地数据。

## 工作原理与边界

- 采集使用**本机 Chromium 内核浏览器**打开淘宝页面，读取页面本身呈现的公开信息。
- 登录需要**你自己扫码**，登录态只保存在本机专属浏览器配置目录里，程序不上传账号或 Cookie。
- **不注入、不修改、不逆向**任何客户端，不提供任何绕过风控或验证码的能力。
- 遇到登录失效或淘宝要求验证时，本次采集**记录失败并停止**，不会自动高频重试。
- 采集频率请自行控制在合理范围，尊重平台规则。

## 开源版与商业版

- 本仓库是**开源社区版**：授权模块不在仓库内，`src/licensing.py` 提供免激活实现，全部本机功能开箱可用。
- 商业发行版在此之上包含离线激活、安装包与增值服务，不属于本仓库范围。
- `app.py` 会优先加载 `src/license_client.py`，找不到时自动回退到 `src/licensing.py`，因此两种版本共用同一套业务代码。

## 目录结构

```
app.py                 FastAPI 应用与全部 HTTP 接口
launch_latest.py       启动入口（复用已安装版本的数据目录）
monitor_runner.py      每日监控任务执行器
src/
  database.py          SQLite 数据层（项目、快照、竞品记录、监控任务）
  browser_search_collector.py  浏览器采集与页面解析
  collector.py         商品详情采集
  market_analysis.py   市场统计与模型分析
  competitor_analysis.py 竞品分析
  competitor_intelligence.py 竞品历史与变化
  monitor_changes.py   变化检测
  reports.py           XLSX / ZIP / HTML 导出
  product_link_resolver.py  链接与分享文案解析
  licensing.py         开源版授权实现（免激活）
static/                单页前端（原生 HTML/CSS/JS）
tests/                 单元测试
```
